# Asset Provenance Register

## Current state

The website currently uses no external image, stock-photo, icon-package or font-file assets.

The previous local JPEG files `assets/hero.jpg`, `assets/studio.jpg` and `assets/texture.jpg` were removed because their commercial provenance was unresolved.

The previous AI-generated demonstration logo was removed from the implementation. The current visible brand mark is a simple text/CSS construction and does not depend on an external artwork file.

## Release rule

No asset with unclear provenance should enter a commercial distribution package when an owned, commissioned, public-domain, or clearly commercially licensed replacement is available.

## Required evidence for future assets

Record the source, creator, licence, permitted commercial use, attribution requirement and date acquired for each final image, icon, font or artwork asset.
